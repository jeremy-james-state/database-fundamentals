A type is a coarse promise.

INTEGER says whole numbers, not that quantity is at least one.

Constraints are the finer promises.

NOT NULL means the fact must exist.

name TEXT NOT NULL.

The engine refuses an insert that skips it.

DEFAULT fills a value when the insert omits the column.

DEFAULT zero for a counter.

DEFAULT CURRENT_TIMESTAMP for created_at.

DEFAULT is not a substitute for NOT NULL if you still want the column present.

They pair well.

CHECK is a boolean test on the row.

CHECK quantity greater than zero.

CHECK rating BETWEEN one AND five.

CHECK price greater than or equal to zero.

The test may mention more than one column.

CHECK end_on greater than or equal to start_on.

Keep CHECKs cheap and obvious.

A CHECK that looks up another table is a foreign key, or a trigger, depending on the engine.

SQLite CHECKs are real if you keep them on.

Some old environments skipped them.

Know your engine.

Do not encode a unique rule in CHECK when UNIQUE exists.

Use the tool that states the meaning.
