Partial dependency is the name of the crime.

It shows up when the primary key is composite.

If the key is order_id plus product_id, product_name depends only on product_id.

It does not need the order to be true.

So product_name on that table will repeat on every order that sells the product.

Update the name on one line, miss the others, and the catalog disagrees with itself.

Those are insert, update, and delete anomalies from a partial dependency.
