Procedures can take parameters and branch with `IF` / `ELSEIF` / `ELSE`.

## Prerequisites

- [Connect to MySQL](/how-to/connect-to-mysql)
- [Stored procedures](/concepts/stored-procedures)

## Create and call

<Steps>
  <Step title="Set a statement delimiter (mysql client)">
    Procedure bodies use `;` inside `BEGIN` … `END`. Change the client delimiter so the whole `CREATE` is one unit:

    ```sql
    DELIMITER //

    CREATE PROCEDURE credit_account(IN account_id INT, IN amount INT)
    BEGIN
      UPDATE accounts
      SET balance = balance + amount
      WHERE id = account_id;
    END //

    DELIMITER ;
    ```
  </Step>
  <Step title="Call it">
    ```sql
    CALL credit_account(1, 10);
    ```
  </Step>
  <Step title="Optional: branch inside">
    ```sql
    DELIMITER //

    CREATE PROCEDURE adjust_balance(IN account_id INT, IN amount INT)
    BEGIN
      IF amount >= 0 THEN
        UPDATE accounts SET balance = balance + amount WHERE id = account_id;
      ELSE
        UPDATE accounts SET balance = balance + amount WHERE id = account_id;
      END IF;
    END //

    DELIMITER ;
    ```
  </Step>
</Steps>

## Verify the result

You succeeded when `CALL` changes the row and a second `CALL` with other arguments works without rewriting the `UPDATE`.

## Troubleshooting

- **Syntax error at BEGIN**: restore `DELIMITER ;` after creating, or the client split the body early.
- **Unknown procedure**: `USE` the database where you created it.
