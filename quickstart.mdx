## Prerequisites

- The `sqlite3` command
- A `books.db` file with a `books` table that has a `title` column

## Get started

<Steps>
  <Step title="Open the database">
    In a terminal:

    ```bash
    sqlite3 books.db
    ```

    The prompt becomes `sqlite>`. See [open a SQLite database](/how-to/open-a-database) if this fails.
  </Step>
  <Step title="Select every column">
    `*` is all columns. `FROM` names the table, not the file.

    ```sql
    SELECT *
    FROM books;
    ```
  </Step>
  <Step title="Peek at ten titles">
    ```sql
    SELECT title
    FROM books
    LIMIT 10;
    ```

    End the statement with a semicolon. Leave SQLite with `.quit`.
  </Step>
</Steps>

You succeeded when ten titles (or fewer) print. Continue with the [Tutorial](/tutorials/query-a-table) for `WHERE`, `LIKE`, `ORDER BY`, and aggregates.
