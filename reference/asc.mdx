---
title: "ASC"
description: "Sorts least to greatest. A to Z for text."
---

This is the default if you omit `ASC` and `DESC` on `ORDER BY`.

## Syntax

```sql
SELECT column
FROM table
ORDER BY expression ASC;
```

## Arguments

<ParamField body="expression" type="column or expression" required>
  The value to sort. `ASC` after it is optional because it is already the default.
</ParamField>

## Examples

<CodeGroup>
```sql Lowest first
SELECT title, rating
FROM books
ORDER BY rating ASC
LIMIT 10;
```
</CodeGroup>
