---
title: "COMMIT"
description: "Saves all statements in the current transaction permanently."
keywords: ["CS50"]
---

After `COMMIT`, other connections can see the new data. Durability is the **D** in [ACID](/concepts/transactions).

## Syntax

```sql
COMMIT;
```

## Examples

<CodeGroup>
```sql Save the unit
BEGIN TRANSACTION;

UPDATE accounts
SET balance = balance - 10
WHERE id = 1;

COMMIT;
```
</CodeGroup>
