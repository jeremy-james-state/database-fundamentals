---
title: "DROP VIEW"
description: "Removes a view from the schema. Underlying tables stay."
keywords: ["CS50"]
---

Does not delete rows from base tables. Only the saved query goes away.

## Syntax

```sql
DROP VIEW view_name;
```

## Arguments

<ParamField body="view_name" type="identifier" required>
  The view to remove.
</ParamField>

## Examples

<CodeGroup>
```sql Drop a view
DROP VIEW average_book_ratings;
```
</CodeGroup>
