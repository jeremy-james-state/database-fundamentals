---
title: "EXCEPT"
description: "Returns rows from the first query that are not in the second."
keywords: ["CS50"]
---

Both queries must have the same number of columns and comparable types.

## Syntax

```sql
SELECT column
FROM table1
EXCEPT
SELECT column
FROM table2;
```

## Examples

<CodeGroup>
```sql Authors who do not translate
SELECT name
FROM authors
EXCEPT
SELECT name
FROM translators;
```
</CodeGroup>
