---
title: "EXECUTE"
description: "Runs a prepared statement with bound values."
---

## Syntax

```sql
EXECUTE statement_name USING @variable, ...;
```

## Arguments

<ParamField body="statement_name" type="identifier" required>
  Name from [PREPARE](/reference/prepare).
</ParamField>

<ParamField body="USING @variable" type="session variable">
  One variable per `?` placeholder, in order.
</ParamField>

## Examples

<CodeGroup>
```sql MySQL
SET @id = 1;
EXECUTE balance_check USING @id;
```
</CodeGroup>
