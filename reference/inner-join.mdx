---
title: "INNER JOIN"
description: "Keeps only rows that match on both tables."
keywords: ["CS50", "INNER JOIN", "matching rows only"]
---

`JOIN` without a qualifier is `INNER JOIN` in SQLite. Unmatched rows are dropped.

## Syntax

```sql
SELECT column
FROM table1
INNER JOIN table2
  ON table1.column = table2.column;
```

## Examples

<CodeGroup>
```sql Explicit inner
SELECT title, stars
FROM books
INNER JOIN ratings
  ON ratings.book_id = books.book_id;
```
</CodeGroup>
