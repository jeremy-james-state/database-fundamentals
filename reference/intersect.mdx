---
title: "INTERSECT"
description: "Returns rows that appear in both queries."
keywords: ["CS50", "INTERSECT", "rows in both"]
---

Both queries must have the same number of columns and comparable types.

## Syntax

```sql
SELECT column
FROM table1
INTERSECT
SELECT column
FROM table2;
```

## Examples

<CodeGroup>
```sql Names in both tables
SELECT name
FROM authors
INTERSECT
SELECT name
FROM translators;
```
</CodeGroup>
