---
title: "LEFT JOIN"
description: "Keeps every row from the left table. Missing matches are NULL."
keywords: ["CS50"]
---

`LEFT JOIN` is an outer join. The left table is the one in `FROM`.

## Syntax

```sql
SELECT column
FROM table1
LEFT JOIN table2
  ON table1.column = table2.column;
```

## Examples

<CodeGroup>
```sql Books without ratings
SELECT title, stars
FROM books
LEFT JOIN ratings
  ON ratings.book_id = books.book_id;
```
</CodeGroup>
