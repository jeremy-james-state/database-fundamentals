---
title: "MAX"
description: "Returns the largest value."
keywords: ["CS50", "MAX", "largest"]
---

For text, that is latest in sort order, not the longest string.

## Syntax

```sql
SELECT MAX(column)
FROM table;
```

## Arguments

<ParamField body="column" type="identifier" required>
  The column to compare. `NULL` is skipped.
</ParamField>

## Examples

<CodeGroup>
```sql Highest rating
SELECT MAX(rating)
FROM books;
```
</CodeGroup>
