---
title: "MIN"
description: "Returns the smallest value."
---

For text, that is earliest in sort order, not the shortest string.

## Syntax

```sql
SELECT MIN(column)
FROM table;
```

## Arguments

<ParamField body="column" type="identifier" required>
  The column to compare. `NULL` is skipped.
</ParamField>

## Examples

<CodeGroup>
```sql Lowest rating
SELECT MIN(rating)
FROM books;
```
</CodeGroup>
