---
title: "NOT NULL"
description: "Rejects a missing value in that column."
keywords: ["CS50", "NOT NULL", "required value"]
---

A [column constraint](/concepts/constraints). `NULL` means unknown, not the number zero and not an empty string. Skip it on a [PRIMARY KEY](/reference/primary-key): that key already requires a value.

## Syntax

```sql
CREATE TABLE table_name (
  column_name STORAGE_CLASS NOT NULL
);
```

## Arguments

<ParamField body="column_name" type="identifier" required>
  Inserts that omit this column fail unless a [DEFAULT](/reference/default) supplies a value.
</ParamField>

## Examples

<CodeGroup>
```sql Required name
CREATE TABLE stations (
  id INTEGER,
  name TEXT NOT NULL,
  PRIMARY KEY (id)
);
```
</CodeGroup>
