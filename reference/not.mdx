---
title: "NOT"
description: "Negates a WHERE condition."
keywords: ["CS50", "NOT", "negation"]
---

Put `NOT` in front of the condition you want to reverse.

## Syntax

```sql
SELECT column
FROM table
WHERE NOT condition;
```

## Arguments

<ParamField body="condition" type="boolean expression" required>
  The test to reverse. `NOT` does not replace `!=` for a simple inequality, but both can express “is not this value.”
</ParamField>

## Examples

<CodeGroup>
```sql Negate equality
SELECT title, format
FROM books
WHERE NOT format = 'hardcover';
```
</CodeGroup>
