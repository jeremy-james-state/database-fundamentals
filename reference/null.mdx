---
title: "NULL"
description: "Marks a missing value. Test it with IS NULL or IS NOT NULL."
keywords: ["CS50"]
---

Do not use `=` with `NULL`. Equality is not how missing values compare.

## Syntax

```sql
SELECT column
FROM table
WHERE column IS NULL;

SELECT column
FROM table
WHERE column IS NOT NULL;
```

## Arguments

<ParamField body="IS NULL" type="test">
  The value is missing.
</ParamField>

<ParamField body="IS NOT NULL" type="test">
  The value is present.
</ParamField>

## Examples

<CodeGroup>
```sql Missing
SELECT title, translator
FROM books
WHERE translator IS NULL;
```
</CodeGroup>
