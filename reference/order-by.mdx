`ORDER BY` works for numbers and for text. Direction is `ASC` or `DESC` after each expression.

## Syntax

```sql
SELECT column
FROM table
ORDER BY expression [ASC | DESC] [, expression [ASC | DESC] ...];
```

## Arguments

<ParamField body="expression" type="column or expression" required>
  Usually a column name. Earlier expressions in the list take priority. Later ones break ties.
</ParamField>

## ASC

`ASC` sorts least to greatest (A to Z for text). It is the **default** if you omit `ASC` and `DESC`.

```sql
SELECT title, rating
FROM books
ORDER BY rating ASC
LIMIT 10;
```

## DESC

`DESC` sorts greatest to least (Z to A for text). Use it when you want the highest values first.

```sql
SELECT title, rating
FROM books
ORDER BY rating DESC
LIMIT 10;
```

## Examples

<CodeGroup>
```sql Default ascending
SELECT title, rating
FROM books
ORDER BY rating
LIMIT 10;
```

```sql Descending
SELECT title, rating
FROM books
ORDER BY rating DESC
LIMIT 10;
```

```sql Two columns
SELECT title, rating, votes
FROM books
ORDER BY rating DESC, votes DESC
LIMIT 10;
```
</CodeGroup>
