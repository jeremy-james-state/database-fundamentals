---
title: "REVOKE"
description: "Removes privileges previously granted to a user."
keywords: ["CS50", "REVOKE", "remove privilege"]
---

## Syntax

```sql
REVOKE privilege [, privilege] ...
ON database.table
FROM 'user'@'host';
```

## Examples

<CodeGroup>
```sql MySQL
REVOKE INSERT
ON transit.*
FROM 'analyst'@'localhost';
```
</CodeGroup>
