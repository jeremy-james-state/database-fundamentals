---
title: "TRIM"
description: "Returns the string with leading and trailing whitespace removed."
keywords: ["CS50", "TRIM", "strip spaces"]
---

A [scalar function](/concepts/sql). It does not change stored rows until you [UPDATE](/reference/update) a column with the result.

## Syntax

```sql
trim(column)
```

## Arguments

<ParamField body="column" type="text" required>
  The value to strip. Spaces at both ends go away. Characters in the middle stay.
</ParamField>

## Examples

<CodeGroup>
```sql Clean titles
UPDATE votes
SET title = trim(title);
```
</CodeGroup>
