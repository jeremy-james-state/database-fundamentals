---
title: "UNION"
description: "Returns rows that appear in either query, without duplicates."
---

Both queries must have the same number of columns and comparable types.

## Syntax

```sql
SELECT column
FROM table1
UNION
SELECT column
FROM table2;
```

## Examples

<CodeGroup>
```sql Names from either table
SELECT name
FROM authors
UNION
SELECT name
FROM translators;
```
</CodeGroup>
