---
title: "VACUUM"
description: "Rebuilds the database file and reclaims unused pages on disk."
keywords: ["CS50"]
---

Run after large deletes or [DROP INDEX](/reference/drop-index) when the file should shrink.

## Syntax

```sql
VACUUM;
```

## Examples

<CodeGroup>
```sql Reclaim space
VACUUM;
```
</CodeGroup>
